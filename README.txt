Exercice 3 — Prolonger, enfin correctement
==========================================

1. Dans IntelliJ : File > Open, puis choisissez ce dossier (celui qui contient pom.xml).
2. Ouvrez src/main/java/fr/mediatech/pret/Verifications.java
   et lancez-le (flèche verte à gauche de main, ou clic droit > Run).
3. Au départ, presque toutes les lignes sont « À FAIRE » ou « ÉCHEC ».
   Chaque ligne indique le TODO qui la fera passer en OK.
4. Complétez les TODO numérotés, dans l'ordre :
     TODO 1 à 3 dans PeriodeEmprunt.java
     TODO 4 et 5 dans Emprunt.java
   Relancez Verifications après chaque TODO.
5. Objectif : toutes les lignes en OK.

Question pour les plus rapides : au départ, 2 vérifications sont déjà OK,
alors que vous n'avez rien écrit. Pourquoi ? Et pourquoi la seconde,
toute seule, ne prouve rien ?

Ne modifiez pas Verifications.java, Isbn.java, EmpruntId.java ni ProlongationRefusee.java.
Isbn.java est un exemple complet de value object : inspirez-vous-en.
